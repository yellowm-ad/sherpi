## 왜 이렇게 했나

| 선택 | 이유 |
|---|---|
| 로봇 → 서버는 **HTTP POST** | 지속 연결을 유지할 필요가 없다. 네트워크가 끊겼다 붙어도 다음 POST부터 자동 복구되고, 끊긴 동안은 최대 30개까지 로컬 버퍼링했다 한 번에 올린다 |
| 서버 → 앱은 **SSE** | 서버→클라이언트 단방향이라 용도에 정확히 맞는다. `EventSource`가 끊기면 자동 재연결하고 `Last-Event-ID`로 유실분을 이어받는다 |
| 명령은 **로봇이 폴링** | 로봇에 인바운드 포트를 열 필요가 없다. LTE 테더링·스마트폰 핫스팟에서 필수 |
| 영상은 **P2P WebRTC** | 서버를 안 거쳐 지연이 낮고 Vercel 대역폭 비용이 0 |

### ⚠️ Vercel 함수 실행시간 제한

Vercel Functions는 WebSocket과 SSE를 지원하지만 **함수 최대 실행시간 제한**을 받습니다.

| 플랜 | 기본 | 최대 |
|---|---|---|
| Hobby | 300초 | 300초 |
| Pro | 300초 | 800초 (베타 1,800초) |

SSE 스트림도 이 제한에 걸려 끊깁니다. 따라서 **클라이언트 재연결이 필수**이고,
`src/hooks/useRobotStream.ts` 가 그걸 처리합니다. Hobby 플랜으로 충분합니다.

SSE가 불안정하면 2초 폴링으로 폴백하세요.

## 로봇 안의 처리 — 0.04초 한 사이클 (2026-11-01)

```
HX711 count ─┐                    ┌─ θ̂, d̂, 1σ ─┐
AS5600 12bit ├─ ① 구하기 ─ ② EKF ─┤            ├─ ③ L0~L3 ─ ④ v·δ·릴 L̇
카메라 u,h px ┘  T, L, θ            └─ 지도 위치  ┘    (HOLD 래치)
```

- 같은 계산이 웹(`src/lib/sherpy/core`, 시뮬레이터·시연 모드)과 로봇(`robot/sherpy_core`)에 있다. 골든 테스트로 일치를 확인한다.
- 텔레메트리(1 Hz)는 결과만 올린다: `tension_n`, `tension_filt_n`, `leash_len_m`, `dog_bearing_deg`, `dog_dist_m`, `dog_sigma_m`, `dog_track`.
- 앱은 로봇 GPS·방위 + θ̂·d̂ 로 강아지 지도 위치를 계산한다 (`lib/sherpy/geo.ts`, WGS84 국소 접평면).
- 식·검증·출처: [MATH_MODEL.md](MATH_MODEL.md)

## 안전 정책 ⚠️

> **원격 정지는 보조 수단입니다. 1차 안전장치는 로봇 본체의 ESC 전원 스위치(모터 전원 차단)입니다.**

명령이 네트워크를 경유하므로 약 1초의 지연과 단절 가능성이 있습니다.
네트워크에 의존하는 정지를 안전설계의 주 수단으로 삼으면 안 됩니다.
ESC 전원 스위치는 파이 프로그램과 상관없이 모터 전원을 직접 끊으므로, 파이가 멈춰 PWM 이 마지막 값으로 남아도 바퀴가 섭니다.
스위치는 차체 뒤쪽, 사람 손이 바로 닿는 곳에 둡니다. (GPIO17 E-stop 버튼은 선택 사항 — 달면 소프트웨어 정지가 하나 더 생길 뿐 1차 수단은 아닙니다.)

구현상 지켜야 할 것:

1. 앱 UI에 위 문구를 노출한다 (`EstopButton`, 대시보드 하단)
2. `START_FOLLOW` 는 모달 확인을 거친다
3. 로봇은 서버 응답을 **3초 이상 못 받으면 스스로 감속·정지**한다
   (`robot/bridge/config.py` 의 `WATCHDOG_SEC`)
4. ESTOP 버튼은 **1초 길게 누르기**로 오작동을 막는다
5. ESTOP은 명령 큐 순서를 무시하고 최우선 반환된다

## 명령 수명주기

```
앱 POST  /commands            → pending
로봇 GET /commands/pending    → sent   (sent_at 기록)
로봇 POST /commands/:cid/ack  → acked
10초 경과 미응답               → expired
```

## GPS — 보호자 폰으로 대체

BOM에 GPS 모듈이 없습니다. 보호자 스마트폰의 `navigator.geolocation` 값을
로봇 위치로 사용합니다.

- 보호자가 로봇 바로 옆에 있으므로 오차는 수 미터, 지도 표시용으로 충분
- 추가 비용 0, 배선 0
- 텔레메트리의 `gps_src` 가 `"phone"` 이면 앱이 그 사실을 표시한다
- 나중에 로봇에 GPS를 달면 `"robot"` 으로 바뀔 뿐, 플랫폼 코드는 그대로

## 배터리 잔량 — P2로 유예

파이에는 ADC가 없어 3S LiPo 전압을 직접 읽을 수 없습니다.
ADS1115 + 분압저항이 필요한데 BOM에 없습니다.

- **P1**: `battery_v` 를 `null` 로 보내고 앱은 "측정 없음" 표시.
  ESC의 저전압 보호(LVC)에 맡긴다
- **P2**: ADC 추가 시 12.6V=100% / 11.1V=50% / 9.9V=0% 로 매핑
