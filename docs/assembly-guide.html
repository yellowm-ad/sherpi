브레드보드 위에 제어부를 꾸미고 차체에 올리기까지의 순서입니다. 핀 번호는 저장소의 robot/bridge/config.py 배정과 같습니다. 단계마다 배선도의 ▶ 연결 순서 재생을 누르면 선이 꽂히는 순서대로 그려지고, 오른쪽 목록의 줄을 누르면 그 선 하나만 강조됩니다. 단계를 끝낼 때마다 앱 로봇 → 로봇 관리 → 배선 점검을 누르면 부품이 직접 대답하는지, 웹에서 보낸 시험값이 구동부 드라이버·표시기까지 가는지 단계별로 ✓ / ✕ 로 보여 줍니다. (2026-11-14 검토 반영: venv 파이썬 경로, E-stop 에이전트 연동, GPS 보드레이트, ESC 켜는 순서)

부품 상태 — 사진 13장 기준

부품상태메모
Raspberry Pi 5 + 타워 쿨러바로 사용팬은 FAN 단자에 연결된 상태. GPIO 40핀 접근 가능.
브레드보드 830홀 ×2바로 사용전원 레일이 가운데(30열 근처)에서 끊김 — 2단계에서 점퍼로 잇기.
점퍼 F/F · M/M 40P, Grove↔암 점퍼바로 사용파이 핀(수) → 브레드보드(구멍)는 M/F가 필요. 없으면 F/F 끝에 M/M을 이어 대신 씀.
Grove AS5600 (12-bit, v1.0)바로 사용Grove 단자 + DIR 스위치. 자석은 지름 방향이어야 함.
PCA9685 (SunFounder) ×2바로 사용둘 다 주소 0x40 → 한 장만 연결, 한 장은 예비.
TM1637 4자리 표시기개수 확인사진엔 1개. 코드는 RED(장력)·BLUE(줄 길이) 2개 기준.
SparkFun HX711납땜 필요핀 헤더 미장착. 기본 10회/초(RATE 점퍼 닫힘).
CAS SBA-50L 로드셀납땜 필요50kgf · 3.0mV/V. 빨강 E+, 검정 E−, 초록 신호+, 흰 신호−, 투명 실드.
NEO-6M GPS (GPS6MV2)납땜 필요VCC·RX·TX·GND 구멍에 헤더 없음. 패치 안테나는 u.FL.
FULREE 12/24V→5V 5A 컨버터바로 사용입력 빨강/검정, 출력 노랑(+)/검정. 선 연결은 레버 커넥터로.
CNHL 3S 5300mAh ×4바로 사용XT60. 9.9V(셀당 3.3V) 아래로 쓰지 않기.
1% 금속피막 저항 키트지금은 불필요이 구성에선 내부 풀업을 씀.
E-stop 버튼 (NO 접점, 나사 단자)구매사진에 없음. 6단계 전에 필요.
레버 커넥터(WAGO 221 등) · 인라인 퓨즈홀더+5A 퓨즈 · XT60 Y케이블 · XT60 피그테일 · USB-C(수)↔나사단자 어댑터구매납땜 없이 차량 전원(10단계)을 꾸미는 재료.
멀티미터 · LiPo 안전백 · 마스킹테이프준비측정·충전·선 라벨용.

장치장치 핀연결 위치선 색(권장)

파이 5에서 pinout 명령을 치면 화면에 핀 그림이 나옵니다. 1번 핀은 USB 포트 반대쪽 끝, 안쪽 줄이고, 보드 가장자리 쪽 줄이 짝수(2번 = 5V)입니다.
